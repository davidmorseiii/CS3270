Required Columns

The uploaded CSV must include the following columns (additional columns are ignored):

  • Location — City or region name
  • MinTemp — Minimum daily temperature (°C)
  • MaxTemp — Maximum daily temperature (°C)
  • Rainfall — Daily rainfall (mm)
  • RainToday — Whether it rained today (Yes/No)

Maximum file size: 50 MB. The standard Australian Weather Training Data.csv file is fully compatible.
